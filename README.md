# ui-ux-principles

一个 Claude Code skill：七条通用 UI/UX 设计原则——一致、少操作、每个操作都有即时反馈、能挽回、易上手、受限输入优先、可操作的元素一眼可辨。适用于任何有界面和交互的产品（应用、网站、工具、仪表盘、游戏/mod），用于设计新界面、审查现有界面和给出改进方案。

A Claude Code skill with seven general UI/UX principles: consistency, low interaction cost, immediate feedback, recoverability, learnability, constrained-input-first, and affordance.

## 安装 Install

把 `SKILL.md` 放到 `~/.claude/skills/ui-ux-principles/SKILL.md`：

```bash
mkdir -p ~/.claude/skills/ui-ux-principles
curl -L https://raw.githubusercontent.com/Wonderfon/ui-ux-principles/main/SKILL.md -o ~/.claude/skills/ui-ux-principles/SKILL.md
```
